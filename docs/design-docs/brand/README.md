# KeylorFit G4 Brand Assets

Canonical approved KeylorFit brand mark: **G4 — Forward Lean K**.

## Source of truth
The editable vector master lives in the Figma file `KeylorFit — Logo Exploration`, frame `Brand Assets — G4 Forward Lean`.

## Variants
- `keylorfit-g4-mark-yellow.svg` — primary mark on dark/navy backgrounds (Auth).
- `keylorfit-g4-mark-white.svg` — photographic/dark backgrounds (Welcome).
- `keylorfit-g4-mark-teal.svg` — secondary brand use.
- `keylorfit-g4-mark-black.svg` — light backgrounds / monochrome.

## Formats and runtime use
- SVG is the canonical scalable asset for web, docs, design, and future vector-capable clients.
- The current React Native app does not include `react-native-svg`; mobile runtime should therefore consume transparent PNG exports generated from these canonical SVGs rather than reimplementing the mark in code.

Do not recreate the mark with emoji, text glyphs, CSS polygons, or ad-hoc geometry.
